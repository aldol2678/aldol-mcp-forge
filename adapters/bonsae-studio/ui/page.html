01 / 구조와 접근성

디자인 분석

검사할 HTML과 CSS를 입력하세요. 원본 파일은 변경하지 않습니다.

02 / 디자인에서 구현으로

디자인 시스템

목표와 컴포넌트의 역할·상태를 명시하면 세움에 전달할 명세를 생성합니다.

goal, components, tokens를 입력합니다. 각 컴포넌트에는 name, role, states, mobile_behavior가 필요합니다.

03 / 화면과 근거

시각 검수

실제 검사 자료를 전달하세요. 렌더링이나 픽셀 검사가 수행되지 않은 항목은 미검증 상태로 남습니다.

최대 128KiB. 자료는 실행 시 검수 서버로 전달됩니다.

파일을 읽으면 입력이 채워집니다. css와 검사 폭(viewports: 390·820·1280)을 조정할 수 있습니다. 검사 가능 범위는 결과에 표시됩니다.

ASSET FACTORY / 연계 검수

에셋 검수

Asset Factory의 연결 가능한 검사 범위를 확인하고 결과를 함께 보관합니다.

현재 입력 범위

이 화면은 에셋 목록의 메타데이터를 전달합니다. 파일 내용·픽셀·권리·엔진 호환성을 검사했다는 의미는 아닙니다.

LOCAL / 검수 기록

검수 기록

SYSTEM / 연결
